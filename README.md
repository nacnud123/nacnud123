### About me

Hello, and welcome to my GitHub. I'm a software engineer and game programmer based in Massachusetts. I like building systems from scratch, especially the kind where the solution isn't obvious when you start. A lot of my projects come from wanting to understand how something actually works, so I'll just rebuild it myself and find out.

Most of my work is in C#, both in Unity and in plain C# with no engine at all. Every once in a while I get the itch to make a voxel game, so I've built a few from scratch in C# with OpenTK and in C++ with raw OpenGL. They always end up turning into Minecraft clones, so I call them DuncanCrafts. On the Unity side I've shipped a solo roguelike on Steam and led a 7-person team through my thesis game, a 2D open world roguelike RPG built from the ground up.

- MFA in Game Programming and a BA in Interactive Media, both from Clark University (Dean's List)
- Showed games at **PAX East** four years running (2023, 2024, 2025, 2026)
- Currently spending most of my time on low-level graphics, voxel engine architecture, in Unity, and procedural generation
- Easiest way to reach me is **978DuncanArmstrong@gmail.com**

### Featured Projects

**[DC Indev](https://github.com/nacnud123/DC-Indev-Public)** — *C#, OpenTK, OpenGL*
A voxel engine built from scratch, aiming to be a feature clone of Minecraft Indev 20100223. It's got procedural terrain with caves and trees, sunlight and block light propagation, 28+ block types, pig and sheep entities with A\* pathfinding, hostile mob AI, crafting, survival mechanics, a day/night cycle, and an ImGui UI. No game engine, just me and OpenTK. As of version 1.0R I consider it finished.

**[DuncanCraft 2000](https://github.com/nacnud123/DuncanCraft-2000-Public)** — *C#, OpenTK, OpenGL*
A Minecraft Classic clone that started as a weeklong project and ballooned into four months. This was my first real OpenTK/OpenGL project. It has fast infinite worlds, saving and loading, caves, and lighting. Getting light to propagate correctly across chunk borders nearly broke me, but it works.

**[C# Prelude of the Chambered](https://github.com/nacnud123/CSharp-Prelude-of-the-Chambered)** — *C#, MonoGame*
A port of Notch's Ludum Dare game from Java into C#/MonoGame. I really like the look of Prelude of the Chambered, so I ported it both to see how it was built and to use as a base for a similar game down the line. Mostly an exercise in reverse-engineering game logic from someone else's code.

**[MarkovFun](https://github.com/nacnud123/MarkovFun)** — *Python*
A Markov chain text generator I made in my free time. It reads an input corpus and spits out statistically probable sentences. Do they make sense? Not really. Are they fun? Yeah. Written from scratch with no ML libraries.
